# SECURITY.md

SECURITY.md tells people how to report a vulnerability safely. GitHub shows it as the project's security policy.

**Owns:**

- Where to report.
- What to include.
- Which versions are supported.
- What happens next.

## You have it when

- A reporter knows where to send a report and what happens next.
- Nothing in it asks them to report in public.

## Skeleton

```markdown
# Security

## Report a vulnerability

<where to send it, and that it must not be a public issue>

## What to include

<the details that help us reproduce it>

## Supported versions

<which versions get fixes>

## What happens next

<how fast we reply, and how we disclose>
```
