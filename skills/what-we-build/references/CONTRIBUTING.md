# CONTRIBUTING.md

CONTRIBUTING.md tells outside contributors how to help. GitHub links it from issues and pull requests.

**Owns:**

- Setup.
- How work flows: branches, commits and reviews.
- The checks that must pass.
- Where to ask.

Draft it at the end of a session, once the workflow is known.

## Guidelines

- **State the bar for a change,** so contributors know before they invest.
- **List the checks that must pass,** and the script that runs them.

## You have it when

- A contributor can set up and send a change without asking anyone.
- The bar for a change is stated before they start.

## Skeleton

```markdown
# Contributing

## Before you start

<the bar for a change, and where to ask first>

## Set up

<how to set it up, or the script that does>

## Make a change

<branch, commit and review flow>

## Checks

<the checks that must pass, and how to run them>
```
