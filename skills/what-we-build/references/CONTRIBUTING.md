# CONTRIBUTING.md

CONTRIBUTING.md tells outside contributors how to help. GitHub links it from issues and pull requests.

## What it holds

- [YES] setup.
- [YES] how work flows through branches, commits and reviews.
- [YES] the checks that must pass.
- [YES] where to ask.

## How to write it

- [YES] state the bar for a change so contributors know before they invest.
- [YES] list the checks that must pass with the script that runs them.

## You have it when

- A contributor can set up and send a change without asking anyone.
- The bar for a change is stated before they start.

## Skeleton

```markdown
# Contributing

## Before you start

<the bar for a change, and where to ask first>

## Set up

<how to set it up, or the script that does>

## Make a change

<branch, commit and review flow>

## Checks

<the checks that must pass, and how to run them>
```
