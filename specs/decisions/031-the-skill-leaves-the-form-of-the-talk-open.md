# 031. The skill leaves the form of the talk open

Decided: 2026-11-03

Partly replaced by 034: The rules for a doc are hard and every guide is read at the start, under which only the user ends the talk on a doc.

## The problem

The skill told the agent to decide with lettered options. In one session the agent offered a choice to settle each point before the talk had run its course, and the user asked why it was in a hurry. A rule added against it only restated the symptom. The root was that the talk was not yet enough, and only the two sides together can tell when it is.

## The choice

The skill says what the talk must do and leaves its form to the agent, the user and the host's own style. The agent says when it thinks the talk is enough and names what is still open, so both sides judge it. It may ask to start writing once the talk seems enough. A concrete case from the project or a tool the user knows is always wanted, and a drawing comes when a point has moving parts. The forms of the docs stay as the guides give them, since a doc must read the same in every window.

## Not chosen

- Lettered options only once the talk has narrowed: it fixes a form and only patches the hurry.
- A count of turns or questions as the measure: no run showed the need, and the talk has no such number.
- Free form for the docs too: a reader scans a doc by its form, and two windows would write it two ways.

## Consequences

The skill no longer names lettered options. A host style that asks for them still works, and its options can move the talk on as well as settle it.
