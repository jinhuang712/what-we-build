# 056. The talk has no time limit

Decided: 2026-11-08

## The problem

The first objective asked for a new project's core docs within N hours of talk, and N was never set. A limit also works against the rule that only the user ends a talk, and an agent in a hurry was the reason for that rule.

## The choice

The objective asks only that a new project's core docs are drafted and approved. Nothing limits the hours of talk.

## Not chosen

- A limit set by guess: no run gave a number, and it would push the agent to close a talk.
- A measure of the hours with no limit: pauses and hard topics blur it, so it can wait for a need.

## Consequences

No number watches the risk that the talk grows too long for the user. The answer to that risk stays in how the agent works: each point goes in as soon as it is agreed.
