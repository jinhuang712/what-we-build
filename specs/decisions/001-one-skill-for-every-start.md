# 001. One skill holds every start

Decided: 2026-10-12

## The problem

A project can start from an idea, from running code or from messy docs. A session can also resume one that stopped.

## The choice

One skill holds every start.

## Not chosen

- A skill per start: a user would need to know which one to call.

## Consequences

The starts share the rules, the guides and the wording.
