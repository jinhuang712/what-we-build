# 011. The placement test asks about rules before goals

Decided: 2026-11-03

## The problem

The placement test in SKILL.md gives a fact the home of the first question it answers yes to. Its second question asked whether a fact can be checked with a test or a number, and almost every rule can. So rules such as no code chunks landed in GOALS before the test reached DESIGNS, and a rule for how the work is done had no home in the test at all.

## The choice

Right after the stance question the test asks whether a fact is a commitment the whole design must meet, then whether it is a rule for how the work is done here. Those go to DESIGNS and AGENTS.md. Only then does it ask whether a fact is an effect the project must have with a test or a number. Such a fact goes to GOALS.

## Not chosen

- Only rewording the GOALS question to ask for an effect: the line between an effect and a rule would rest on the agent's judgment alone.
- A push-back in the GOALS guide only: it catches a rule after it was placed, not before.

## Consequences

GOALS then holds only effects, which is what 010: Goals hold only effects asked for. A fact that is a design commitment and can also be checked now goes to DESIGNS first.
